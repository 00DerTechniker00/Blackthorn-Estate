# Quelldaten

`world-regions/` enthält die angehängten Minecraft-Regiondateien und zusätzlich die Regiondateien aus dem früheren `mca.zip`-Import. `world-metadata/level-original.dat` ist die zugehörige beigefügte Level-Metadatei. Referenzbilder liegen unter `references/`. Die Daten sind unverändert vom aktuellen Bauplan getrennt.
